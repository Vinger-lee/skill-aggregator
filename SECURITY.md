# Security Policy

## Supported Versions

| Version | Supported |
|:---|:---:|
| 0.1.x | ✅ |
| < 0.1 | ❌ |

## Reporting a Vulnerability

This project runs locally on your machine and has no network service component. It scans local skill directories and performs text analysis locally.

If you discover a security issue, please open an issue on GitHub describing the concern. Do not include sensitive information.
