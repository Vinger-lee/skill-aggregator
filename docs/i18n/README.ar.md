## ⚡ البداية السريعة

```bash
pip install skill-aggregator
skill-aggregator "إنشاء تحقق من صحة نموذج تسجيل الدخول باستخدام React"
```

## ✨ الميزات

| الميزة | الوصف |
|------|------|
| 🧠 **تحليل النية** | يفهم نيتك الحقيقية وليس فقط الكلمات المفتاحية |
| 🈯 **تقسيم النص الصيني** | jieba للصينية + تعبيرات منتظمة للإنجليزية |
| 🔄 **اكتشاف البيئة** | يكتشف تلقائياً مجلدات المهارات من config.yaml |
| 🎯 **تقييم رباعي المحاور** | كلمات مفتاحية(40%) + مجال(25%) + TF-IDF(20%) + أولوية(15%) |
| 🧹 **تدقيق المهارات** | يفحص أكثر من 400 مهارة بحثاً عن المشكلات |
