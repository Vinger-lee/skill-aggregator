```bash
pip install skill-aggregator
skill-aggregator "Validar formulario de login en React"
```

## ✨ Características

| Característica | Descripción |
|------|------|
| 🧠 **Análisis de intención** | Comprende tu intención real, no solo palabras clave |
| 🈯 **Segmentación china** | jieba + expresiones regulares en inglés |
| 🔄 **Detección de entorno** | Descubre automáticamente los directorios de habilidades |
| 🎯 **Puntuación 4 ejes** | Palabras clave(40%) + Dominio(25%) + TF-IDF(20%) + Prioridad(15%) |
| 🧹 **Auditoría de habilidades** | Escanea 400+ habilidades en busca de problemas |
