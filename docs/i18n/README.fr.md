## ✨ Fonctionnalités

| Fonctionnalité | Description |
|------|------|
| 🧠 **Analyse d'intention** | Comprend votre vraie intention, pas juste les mots-clés |
| 🈯 **Segmentation chinoise** | jieba + expressions régulières anglaises |
| 🔄 **Détection d'environnement** | Découverte automatique des dossiers de compétences |
| 🎯 **Score 4 axes** | Mots-clés(40%) + Domaine(25%) + TF-IDF(20%) + Priorité(15%) |
| 🧹 **Audit de compétences** | Scan automatique des problèmes sur 400+ compétences |
