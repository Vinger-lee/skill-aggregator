## ⚡ 빠른 시작

```bash
pip install skill-aggregator
skill-aggregator "React로 로그인 폼 유효성 검사 만들기"
```

## ✨ 핵심 기능

| 기능 | 설명 |
|------|------|
| 🧠 **의도 분석** | 키워드뿐 아니라 실제 의도를 이해 |
| 🈯 **중국어 분절** | jieba 중국어 + 영어 정규식 |
| 🔄 **환경 인식** | config.yaml에서 스킬 디렉토리 자동 탐지 |
| 🎯 **4축 점수** | 키워드(40%) + 도메인(25%) + TF-IDF(20%) + 우선순위(15%) |
| 🧹 **스킬 진단** | 400개 스킬 문제 자동 스캔 |
