## ✨ Возможности

| Возможность | Описание |
|------|------|
| 🧠 **Анализ намерений** | Понимает реальное намерение, а не только ключевые слова |
| 🈯 **Китайская сегментация** | jieba для китайского + регулярные выражения для английского |
| 🔄 **Обнаружение среды** | Автоматически находит каталоги навыков из config.yaml |
| 🎯 **4-осевая оценка** | Ключевые слова(40%) + Домен(25%) + TF-IDF(20%) + Приоритет(15%) |
| 🧹 **Аудит навыков** | Сканирует 400+ навыков на наличие проблем |
